# Minecraft Regular

Designer: Jacob Debono, JDGraphics Fonts.
Copyright © 2017 by Jacob Debono.

The unmodified font's embedded license description (name ID 13) is:
"Free for Commercial Use".

Author's font listing: https://www.fontspace.com/minecraft-font-f28180

The reference site https://musnom.com declares this exact font as
`MinecraftRegular_Bmg3-s.p.ce778330.otf`. Its font file was retrieved from
https://musnom.com/_next/static/media/MinecraftRegular_Bmg3-s.p.ce778330.otf
on September 18, 2026 and bundled locally as `Minecraft-Regular.otf`.

The original portfolio's main-branch CSS already referenced that hashed
Next.js path, but did not contain the file. This version uses a real local
asset rather than falling back to a different pixel font.
